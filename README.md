### 拓界 Flow · Python 开源审批引擎
面向国产 OA 审批习惯的通用审批流引擎，基于 Odoo 20 + OWL 3 构建。 任何业务模型通过一个 Mixin 即可接入审批，配套可视化流程设计器与审批中心，开箱即用。

#### 核心能力
审批方式：或签、会签、加签、减签，覆盖国内常见会签场景
流程路由：排他网关（条件分支）、并行网关（并行分支/汇聚）、子流程、抄送节点
审批中心：我的待办 / 已办 / 我发起的 / 抄送我的，四视角一站式处理
零侵入接入：业务模型继承 tb.approval.mixin 即获得完整的提交、审批、撤回能力
实例追踪：审批实例图自动生成，高亮当前流转节点，进度一目了然

### 可视化流程设计器
基于 OWL 3 + LogicFlow 2 的画布式设计器，纵向主干 + 条件分支横向展开
连线强制横平竖直的正交折线，自动避让节点，告别杂乱斜线
节点样式定制、连线条件支持画布上直接配置：双击内联编辑与右侧属性面板双向同步
设计器源数据独立存储，与流程引擎解耦，升级不丢图

#### 快速上手
「流程设计」新建流程，拖拽节点搭建审批链路，配置条件分支
业务模型接入 tb.approval.mixin，绑定流程
单据提交后进入审批中心流转，待办消息实时提醒

#### 适用场景
采购申请、合同会签、费用报销、出库放行等需要多级审批与条件路由的业务单据， 尤其适合有会签、并行审批需求的国产化 Odoo 项目。
